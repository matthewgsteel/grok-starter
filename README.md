# grok-starter

A minimal starter template for new projects in a **Proton Drive + Git + Grok** development workspace.

**GitHub:** https://github.com/matthewgsteel/grok-starter

## Why this template?
- Clean git init with main branch
- Sensible .gitignore for common languages/tools
- Basic README
- Ready to copy into your Code/ workspace (see structure below)

## Local path (in your synced workspace)
C:\Users\MGS\Proton Drive\Code\templates\grok-starter

## How to use
1. Copy the entire folder to a new location inside your Code/ directory, e.g.:
   - Code\personal\my-new-project
   - Code\mcp\my-new-mcp-server
   - Code\skills\my-custom-skill
2. cd into the copy
3. Edit README.md, update name, add your code
4. git init (if you want a fresh history) **or** keep this history and git remote add ...
5. Start committing

## Recommended workspace structure
See the README at the root of your Code/ folder (in Proton Drive) for the full layout:
- mcp/
- skills/
- agents/
- tools/
- experiments/
- personal/
- templates/  ← this lives here

## Included
- .gitignore — covers Node, Python, Go, Rust, .NET, IDEs, OS files, etc.
- README.md — this file (customize per project)
